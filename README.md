# AI Prompt Evaluator

A web application for evaluating AI-generated responses, comparing prompt quality, and rating outputs based on accuracy, clarity, reasoning, and usefulness.

## Features

- Submit prompts
- Compare AI responses
- Rate response quality
- Save evaluation history
- Dashboard analytics

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
